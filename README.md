# الحكيمي كام | Alhakimi Cam

أداة Python لـTermux لمعاينة كاميرتك والتقاط صورة **بموافقتك الصريحة**. لا تبدأ الكاميرا إلا بعد ضغط زر التشغيل والموافقة في المتصفح. الصور لا تُرفع أو تُرسل تلقائياً؛ يمكنك حفظها أو فتح قائمة مشاركة Android واختيار التطبيق والمستلم بنفسك.

## التشغيل في Termux

```bash
pkg update
pkg install git python
git clone https://github.com/moteialhakimi/alhakimi-cam.git
cd alhakimi-cam
python alhakimi_cam.py
```

يفتح السكربت الصفحة محلياً عند توفر `termux-open-url`. وإلا افتح `http://127.0.0.1:8765/` في متصفح الهاتف. اضغط **أوافق — تشغيل الكاميرا** وامنح إذن الكاميرا من المتصفح. التقط صورة إن رغبت، ثم اختر **حفظ الصورة** أو **مشاركة يدوية…**. إيقاف الخادم: `Ctrl+C`.

إذا كان المنفذ مشغولاً:

```bash
ALHAKIMI_CAM_PORT=8766 python alhakimi_cam.py
```

ثم افتح `http://127.0.0.1:8766/`.

## الخصوصية والحدود

- الخادم مربوط بعنوان `127.0.0.1` فقط؛ لا ينشئ رابطاً عاماً ولا يقبل اتصالات أجهزة أخرى.
- لا يوجد تسجيل صوتي/فيديو، ولا إذن ميكروفون، ولا رفع أو إرسال تلقائي، ولا حسابات أو كلمات مرور.
- التقاط الصورة اختياري، ويبقى الملف في المتصفح حتى تحفظه أو تختار مستلماً بنفسك عبر قائمة المشاركة.
- لا تستخدم الأداة لتصوير شخص آخر دون علمه وموافقته. لا يمكنها تشغيل الكاميرا خفية أو تجاوز أذونات المتصفح.
- لا تعرض الخادم على الإنترنت أو عبر نفق عام.

## المتطلبات

Python 3 في Termux ومتصفح حديث يدعم `getUserMedia`. لا توجد حزم Python خارجية. قد تحتاج إلى تفعيل إذن الكاميرا للمتصفح من إعدادات Android.
