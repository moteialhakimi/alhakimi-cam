# الحكيمي كام | Alhakimi Cam

أداة Python 3 تعمل في Termux لاختبار كاميرا الجهاز نفسه. الخادم مربوط حصراً بـ`127.0.0.1`، ولا ينشئ رابطاً عاماً أو يقبل اتصالات من أجهزة أخرى. لا تبدأ الكاميرا إلا بعد ضغط المستخدم زر التشغيل وموافقة المتصفح.

## التشغيل في Termux

```bash
pkg update
pkg install git python
git clone https://github.com/moteialhakimi/alhakimi-cam.git
cd alhakimi-cam
python alhakimi_cam.py
```

يفتح السكربت الصفحة عبر `termux-open-url` عند توفره. وإلا افتح يدوياً `http://127.0.0.1:8765/` في متصفح الجهاز نفسه. وافق على إذن الكاميرا من المتصفح بعد ضغط زر **أوافق — تشغيل الكاميرا**. لا يُطلب إذن الميكروفون.

لالتقاط صورة، اضغط **التقاط صورة** بعد ظهور المعاينة؛ ثم اختر **حفظ الصورة يدوياً** إذا رغبت. لا تُحفظ الصورة تلقائياً ولا تُرسل أو تُرفع إلى أي مكان. إيقاف الخادم يكون بالضغط على `Ctrl+C` في Termux.

إذا كان المنفذ الافتراضي مشغولاً، اختر منفذاً بين 1 و65535:

```bash
ALHAKIMI_CAM_PORT=8766 python alhakimi_cam.py
```

ثم افتح `http://127.0.0.1:8766/`. إذا كانت قيمة المنفذ غير صحيحة أو تعذر ربطه، يعرض البرنامج رسالة خطأ؛ تحقق أن المنفذ رقم صالح وغير مستخدم.

## البنية

```text
.
├── alhakimi_cam.py       # إعداد الخادم المحلي والتحقق من المنفذ
├── web/
│   └── index.html        # واجهة HTML/CSS/JavaScript محلية
├── tests/
│   └── test_app.py       # اختبارات المنفذ ومسارات HTTP
└── README.md
```

لا تحتاج الأداة إلى حزم Python خارجية. ملف الواجهة ثابت ويُخدم من المشروع محلياً. سياسة أمان المحتوى تمنع الاتصالات الصادرة (`connect-src 'none'`). لا يجري الخادم اتصالات شبكة صادرة، ولا يسجل مسارات الطلبات أو عناوين IP.

## الخصوصية والأذونات

- الكاميرا لا تُطلب إلا بعد فعل المستخدم الصريح، ثم موافقته في المتصفح.
- تُستخدم الكاميرا للفيديو الحي فقط، والصوت معطل (`audio: false`). لا يوجد تسجيل صوت أو فيديو.
- التقاط الصورة اختياري، وعرضها وحفظها يتمان محلياً وباختيار المستخدم.
- إيقاف الزر أو إغلاق الصفحة يوقف مسارات الكاميرا.
- لا حسابات أو كلمات مرور أو تتبع أو تحليلات أو رفع وسائط.
- لا تستخدم الأداة لتصوير شخص آخر دون علمه وموافقته، ولا تعرض الخادم على الإنترنت أو عبر نفق عام.

## الاختبارات

يتضمن المشروع اختبارات Python القياسية دون تثبيت حزم إضافية:

```bash
python -m unittest discover -s tests -v
```

تتحقق الاختبارات من صحة المنفذ، واستجابة الصفحة بمحتوى الموافقة، ورفض المسارات غير المعروفة، وربط الخادم بعنوان loopback. شغّل الاختبارات من مجلد المشروع.
